# nexus-hub

Lokal webapp optimalisert for Samsung Galaxy Tab A11. Info display/smart hjem integrasjon. 


<img width="1336" height="869" alt="image" src="https://github.com/user-attachments/assets/9a561621-4eea-4960-8794-cfef2d6c5712" />



## Hurtigstart
1. Kopier `.env.example` til `.env` og fyll ut dine verdier:
   `cp .env.example .env`
2. Start serveren:
   `python main.py`
